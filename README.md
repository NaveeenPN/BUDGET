## Budget Planner – C# (First Project)

This is my **first project using C#**, built as part of my **self-learning journey into new technologies** alongside my goal of becoming a **Data Analyst**.

The project is a **simple Budget Planner web application** created using **ASP.NET Core Razor Pages** and **Entity Framework Core**.  
It allows users to manage income records with basic CRUD (Create, Read, Update, Delete) operations.

### Why this project?
- To understand C# fundamentals
- To learn ASP.NET Core and Razor Pages
- To practice database connectivity using Entity Framework Core
- To gain hands-on experience building a real-world application

### Features
- Add, view, edit, and delete income records
- Delete confirmation before removing data
- Clean Razor Pages structure
- Database operations using Entity Framework Core

### Technologies Used
- C#
- ASP.NET Core Razor Pages
- Entity Framework Core
- SQL Server
- Visual Studio

### Note
This project is intentionally kept **simple** and represents my **learning progress** as I explore backend development while building my data analyst skill set.
